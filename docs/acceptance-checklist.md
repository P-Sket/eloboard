# Acceptance Checklist

Use this checklist before merging homepage changes.

## Product

- The page clearly explains what this is.
- The primary visitor has a clear next action.
- The content supports the stated product brief.

## Design

- Desktop layout is polished.
- Mobile layout is polished.
- Navigation is usable.
- Text does not overlap or overflow.
- CTA hierarchy is clear.
- Visual style follows `docs/design-system.md`.

## Engineering

- The app builds.
- Linting or tests pass if configured.
- No unrelated files are changed.
- Components are named clearly.
- Repeated patterns are reusable without premature abstraction.

## Release

- SEO title and description are set.
- Broken links are checked.
- Images have appropriate alt text.
- Deployment target is documented.
