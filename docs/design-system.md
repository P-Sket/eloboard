# Design System

## Visual Direction

Competitive StarCraft 1 ladder interface with a tactical sci-fi feel.

Examples:

- Dark tactical command center
- Race-sensitive theme based on the current rank 1 player
- Compact but readable data table

## Layout Rules

- First viewport must clearly show what EloBoard is.
- The primary CTA must be visible without scrolling on desktop and mobile.
- Avoid marketing-only filler sections.
- Keep repeated content scannable.
- Do not use nested cards.

## Colors

Define semantic colors here instead of scattering one-off values.

| Token | Purpose | Value |
| --- | --- | --- |
| `background` | Page background | Race-dependent dark base |
| `surface` | Panels/cards | Near-black translucent surface |
| `text` | Primary text | Cool white |
| `muted` | Secondary text | Desaturated gray-green |
| `primary` | Main action | Race-dependent highlight |
| `accent` | Small highlights | Race-dependent secondary highlight |

## Typography

| Use | Guidance |
| --- | --- |
| Hero heading | Clear, specific, not vague |
| Section heading | Short and scannable |
| Body copy | Plain, concrete, benefit-oriented |
| Button text | Action verbs |

## Components

Track reusable homepage components here:

- Header
- Hero
- CTA button
- Feature block
- Testimonial
- Pricing card
- FAQ item
- Footer

## Responsive Requirements

- Mobile width: 360px and up
- Tablet width: 768px and up
- Desktop width: 1024px and up
- Text must not overflow buttons, cards, or navigation.
- Navigation must remain usable on small screens.
