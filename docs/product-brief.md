# Product Brief

## Homepage Name

EloBoard

## Purpose

Provide a public StarCraft 1 rating board where players and viewers can check updated standings, match history, race matchups, streaks, and recent form.

## Primary Audience

StarCraft 1 community members who participate in or follow EloBoard matches.

## Primary Action

View the latest ranking and submit match results.

Examples:

- Submit a match result
- Check current rank
- Review recent approved matches

## Secondary Actions

- Search for a player
- Filter by race
- Check matchup records
- Confirm match approval rules

## Required Sections

- Hero with current race theme
- Leaderboard
- Match submission form
- Recent approved matches
- Operation rules

## Brand Notes

Sci-fi competitive ladder, inspired by classic real-time strategy interfaces without using official StarCraft assets.

## Content Inventory

Primary data lives in `data/players.json` and `data/matches.json`.
