# Legacy Race Image Slots

The active site now uses images from `images/<race>/`.
This folder is kept only for older placeholder notes.

Current structure:

```txt
images/zerg/unit.webp
images/zerg/build.jpg
images/zerg/mark.png

images/terran/unit.webp
images/terran/build.webp
images/terran/mark.png

images/protoss/unit.webp
images/protoss/build.jpg
images/protoss/mark.png
```

Usage:

- `unit` appears as the upper active race background.
- `build` appears as the lower active race background and commander panel image.
- `mark` appears in the leaderboard race column instead of text.

Only commit assets you have permission to use on the public site.

Unit and building cards:

- `zerg-unit-2.webp`

- `terran-unit-1.webp`
- `terran-unit-2.webp`
- `terran-building-1.webp`
- `protoss-unit-1.webp`
- `protoss-unit-2.webp`
- `protoss-building-1.webp`

Recommended export:

- WebP
- 1600px wide for hero images
- 600px wide for unit/building images
- Dark or transparent background works best
